# Finan.ai

Aplicacao de controle financeiro com foco em organizacao, metas, extratos e visao clara da saude financeira do usuario.

## O que este projeto mostra

- Autenticacao com Supabase.
- Dashboard financeiro com rotas protegidas.
- Areas de extrato, metas, integracoes e configuracoes.
- Interface em React com componentes shadcn/ui, Radix UI e Tailwind CSS.
- Base preparada para evoluir com IA e recomendacoes financeiras.

## Stack

- React
- TypeScript
- Vite
- Supabase
- TanStack Query
- shadcn/ui
- Tailwind CSS
- Recharts
- Vitest

## Como rodar

```bash
npm install
npm run dev
```

Para build de producao:

```bash
npm run build
```

## Status

Projeto de produto em evolucao, usado como laboratorio de SaaS financeiro, dashboards e fluxos autenticados.
